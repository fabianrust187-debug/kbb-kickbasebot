# Version 0.7.6 — Late Top-5 catch-up

- Managers who missed the Tuesday 22:00 Top-5 deadline can now still submit the missing player afterwards.
- Late submissions are accepted only while the current round is still open; duplicate submissions remain blocked.
- A late submission does not remove or undo any already imposed penalty.
- The Top-5 submit button is automatically restored after the deadline while at least one manager is still missing.
- Once all managers have submitted, the existing finalizer closes the round and removes the button.
- The next regular Friday round still replaces/closes the old round as before.
